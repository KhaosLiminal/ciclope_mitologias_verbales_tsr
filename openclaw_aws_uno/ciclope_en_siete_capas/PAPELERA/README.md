# PAPELERA — Archivo Ontológico del Proyecto Cíclope

## Propósito

Esta carpeta contiene **material histórico, intentos fallidos y documentación ontológica** del proyecto Cíclope. No es basura: es el registro de los procesos que no llegaron a ser outputs finales, pero que contienen decisiones conceptuales, errores instructivos y datos parciales que forman parte de la genealogía del proyecto.

## Contenido

### Auditorías
- `AUDITORIA_COMPILADOR_MONOLITO_20260503.md` — Análisis del compilador original, identificación de problemas estructurales

### Archivos Reconstruidos
- `TSR_CAPA5_FINAL_v1_RECONSTRUIDO.json` — Reconstrucción manual del primer output de CAPA5
- `TSR_CAPA5_FINAL_v2.json` — Versión alternativa que no se usó

### Archivos Huérfanos
- `tsr108_meta-analisis.md` — Meta-análisis aislado que no se integró en el flujo

### Bitácoras
- `BITACORA_ELIMINACIONES.md` — Registro de archivos eliminados y razones

## Criterio de Inclusión

Un archivo llega a PAPELERA cuando:

1. **No es output final** pero contiene decisiones conceptuales relevantes
2. **Es un intento fallido** que enseña algo sobre el proceso
3. **Es documentación ontológica** del proyecto (metadatos sobre metadatos)
4. **Fue generado por error** pero preserva datos parciales valiosos

## Uso

- **Investigadores del proceso:** Aquí encontrarás los fracasos que hicieron posibles los éxitos
- **Desarrolladores:** Casos de estudio de qué no hacer
- **Curadores:** Material para entender las decisiones detrás del dataset final

## Advertencia

**No eliminar esta carpeta.** Aunque no es parte del dataset activo, es parte del archivo ontológico del proyecto. La historia de los errores es tan valiosa como la de los aciertos.
